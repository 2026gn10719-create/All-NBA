# 올느바 (ALL-NBA)

고교 9학년부터 NBA 은퇴까지, 한 시즌씩 쌓아 가는 농구 커리어 시뮬레이터. 브라우저에서 바로 실행되는 단일 HTML 파일(`index.html`)이며, 진행 상황은 브라우저 localStorage에 저장됩니다.

## 고지
이 프로젝트는 비영리 팬 제작 게임이며 NBA 및 어떤 구단·선수·브랜드와도 제휴·후원 관계가 없습니다. 게임 속 선수는 모두 가상입니다. 팀 이름과 브랜드명을 포함한 모든 상표는 각 소유자의 것입니다. 삭제 요청은 이슈로 알려 주세요.

## 실행
`index.html`을 브라우저로 열거나 GitHub Pages(Settings → Pages → main / root)로 배포하세요.
